# v0.4 responsibility migration map

Status: reference for `pi/v0.4-runtime-invariants`. This map classifies the legacy
components named by the v0.3 architecture review. It exists so that **no legacy safety
infrastructure is deleted before an equivalent responsibility exists in the new runtime**.

Legend:

- **shared infra** — still required; used by both paths, must not be weakened.
- **migrated** — the responsibility is now owned by a v0.4 component; the legacy module is
  kept for compatibility/audit until the new-path tests are complete.
- **legacy only** — reachable only through the deprecated pipeline (`--legacy` / `--demo`
  / `--empty`) or programmatic old entry points.
- **deprecate later** — responsibility superseded; removal is safe after independent audit.

| Legacy component | Classification | v0.4 owner / notes |
|---|---|---|
| Guarded executors (`app/tools/execution.py`), `app/validation/sql_guard.py` | shared infra | Unchanged. Read-only roles, AST guard, table allowlist, timeout, bounded fetch, DuckDB path containment, redaction. |
| `SchemaCatalog` / `app/semantic/schema_registry.py` | shared infra | Enforced harder by the compiler (`allowed_operations`, roles, types). |
| `SqliteKnowledgeStore` + seed/ingestion/registry/freshness | shared infra | Read path now ACTIVE-only by default. |
| `CandidateKnowledgeStore` | shared infra | Promotion now preserves provenance/scope and fails closed on conflict-check errors. |
| `KnowledgeGovernance` | migrated + kept | Structured `ConflictRecord`s, idempotent promotion, explicit `ConflictCheckUnavailable`. |
| `EntityLookup` / `MLBPeopleSearch` | shared infra | Still used by `entity_resolution`; identity remains provider/dictionary based (known limitation). |
| Old `AssessmentService` / `app/assessment/judge.py` | migrated | Split into deterministic scope verification (`scope_verification.py`) + `IndependentJudge` (`judge.py`) + `StateProjector` (`state.py`). Old modules remain legacy-only. |
| `Router` permission/cost admission (`app/agent/routing.py`) | migrated (partial) | `ToolCapabilityContract` now declares `cost`, `availability`, `authority` and restriction predicates; the engine records an `ACTION_ADMITTED` event before execution. A full central cost ledger is **not yet** wired (known limitation). |
| `RunRecorder` (`app/persistence/recorder.py`) | migrated (partial) | `EventJournal` (redacted, append-only) + `ToolAttempt` journaling (intent before side effect, outcome after). Old recorder remains legacy-only. |
| `ResumeService` (`app/persistence/resume.py`) | migrated (partial) | Product CLI now wires `SqliteOperationalStore`; `RuntimeConversation.snapshot/restore` persists events/attempts and identity counters. Legacy checkpoint inspection remains for old runs. |
| Checkpoint ordering (`artifact before reference/state`) | migrated | Tools register artifacts, the engine verifies scope, then durable refs/exports are written; an execution intent snapshot precedes side effects. |
| `RunMetrics` / redaction (`app/observability/metrics.py`) | migrated | `events.redact` bounds/redacts every event and detail string; the CLI `--trace` is a projection of the event model. Old metrics remain legacy-only. |
| `BaseballAgent` / `DeterministicCognition` | legacy only | Deprecated entry points. |
| City-based `select_team` | legacy only | The roster tool never guesses from city names. |
| `SemanticCandidate` / dual-parser / requirement pipeline | legacy only | Not used by the default runtime. |
| Old `MetricRegistry`-only SQLAnalysisRequest | legacy only | The new local path uses Safe Analytical IR. |
| `field_resolver.py`, `MessageEnvelope`, unused `RefType` variants | deprecate later | Representational; no runtime convergence required. |
| `app/conversation/service.py` placeholder | deprecate later | Conversation state is owned by `RuntimeConversation`. |

## Deferred (explicitly not in v0.4)

- Historical/official roster membership provider (capability addition; v0.4 only makes the
  current active roster **truthfully refuse** historical scope).
- Pitching adapter and additional validated analytical operators.
- Arbitrary SQL/table/function escape hatches — deliberately never.
- A full token/cost ledger across model + provider calls.
